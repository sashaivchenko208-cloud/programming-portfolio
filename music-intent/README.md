# Семантические признаки музыкальных треков

Тестовое «Разговорные рекомендации музыки по пользовательскому интенту». Один выполненный ноутбук покрывает задания 1–5.

[Открыть в Colab](https://colab.research.google.com/github/sashaivchenko208-cloud/programming-portfolio/blob/main/music-intent/music_intent_musiccaps.ipynb) · [Ноутбук](music_intent_musiccaps.ipynb)

## Результат

- 80 реальных музыкальных фрагментов Google MusicCaps; исходные данные встроены.
- Извлечение жанров, настроений, темпа/энергии, вокала, инструментов и гипотез контекста из текстовых описаний.
- EDA, распределения, корреляции и t-SNE.
- Сравнение TF-IDF, семантического и гибридного представлений, примеры соседей.
- Все 12 кодовых ячеек выполнены локально; проверки входных данных, правил и поиска пройдены.

## Запуск

В Colab выбрать Python 3 и «Выполнить всё». GPU и ключи API не нужны. Исходные записи встроены, результаты выполнения и графики сохранены в ноутбуке. При запуске создаётся папка results с CSV, JSON и графиками. Выполнение в hosted Colab отдельно не проверялось.

## Ограничения

Это текстовый baseline, не анализ аудиосигнала. Аудио не прослушивалось и не распространяется; доступность YouTube-ссылок не проверена. Названия и исполнители отсутствуют в источнике и не выдуманы. Контексты — эвристические гипотезы. Нет доказанного улучшения музыкальных рекомендаций: сравнение по аспектам — слабая диагностика, не независимая оценка релевантности.

Код и документация подготовлены с помощью Codex; помощь ИИ раскрыта в ноутбуке.
